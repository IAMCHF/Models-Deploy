MongoDB Atlas Vector Search enables developers to build semantic search and Retrieval-Augmented Generation (RAG) applications by storing vector embeddings alongside operational data. The solution leverages the Approximate Nearest Neighbor (ANN) algorithm using Hierarchical Navigable Small World (HNSW) graphs to efficiently retrieve semantically similar documents at scale. Each document in the collection can contain both structured metadata fields and a high-dimensional vector embedding, typically generated by models such as OpenAI text-embedding-3-small or Cohere embed-english-v3.0. The vectorSearch index supports cosine similarity, dot product, and Euclidean distance metrics, allowing developers to tune retrieval performance based on their specific use case. Filterable vector searches combine approximate nearest neighbor retrieval with pre-filtering on metadata, ensuring that results satisfy both semantic relevance and structured query constraints simultaneously.
